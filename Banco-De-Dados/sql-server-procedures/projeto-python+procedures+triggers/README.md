# Projeto de Modelagem e Análise de Dados – IMDb

## 1. Descrição do Projeto

Este projeto tem como objetivo a análise e modelagem de dados utilizando o dataset IMDb, explorando conceitos de banco de dados relacional, manipulação de dados com Python e implementação de procedures e triggers no SQL Server.

O trabalho envolve a estruturação de um banco de dados relacional com base em um dataset real, aplicando técnicas de normalização, criação de tabelas relacionadas e consultas SQL para análise das informações.

Além disso, foi realizada a etapa de tratamento e preparação dos dados utilizando Python, garantindo maior qualidade e consistência antes da inserção no banco de dados.

---

## 2. Objetivo

O objetivo do projeto é aplicar conceitos de:

- Modelagem de banco de dados relacional  
- Normalização de dados  
- Relacionamento entre tabelas (chaves primárias e estrangeiras)  
- Manipulação e limpeza de dados com Python  
- Execução de consultas SQL para análise  
- Implementação de procedures e triggers no SQL Server  

---

## 3. Tecnologias Utilizadas

- Python  
- SQL Server  
- Pandas (tratamento de dados)  
- MySQL / SQL Server Management Studio (dependendo do ambiente)  
- Dataset IMDb (Kaggle)  

---

## 4. Estrutura do Banco de Dados

O banco de dados foi modelado com três entidades principais:

- Filmes  
- Diretores  
- Gêneros  

A tabela de filmes possui relacionamentos com as tabelas de diretores e gêneros por meio de chaves estrangeiras, garantindo integridade referencial e evitando redundância de dados.

---

## 5. Processo do Projeto

1. Análise e escolha do dataset IMDb  
2. Tratamento e limpeza dos dados utilizando Python  
3. Modelagem do banco de dados relacional  
4. Criação das tabelas no SQL Server  
5. Criação de procedures e triggers para automação e validação dos dados  
6. Inserção dos dados tratados no banco  
7. Execução de consultas SQL para análise dos dados  
8. Validação dos resultados  

---

## 6. Resultados

O projeto permitiu a aplicação prática de conceitos de banco de dados e análise de dados, demonstrando a importância da organização e estruturação correta das informações para facilitar consultas e gerar insights.
